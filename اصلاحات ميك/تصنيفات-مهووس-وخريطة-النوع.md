# تصنيفات متجر مهووس + خريطة «نوع المنتج ← التصنيف الصحيح»
### مرجع لإصلاح اختيار التصنيف في التطبيق (الدالة `_detect_product_type`)

## 0) الخلاصة الحاسمة
متجر مهووس **شامل** — ليس عطوراً فقط. يبيع: عطور، جمال/عناية، مكياج، عطور جسم وشعر، معطرات منزل، عود/بخور، إكسسوارات، مجموعات هدايا.

**حالة «سوما» (زبدة ترطيب جسم):** تنتمي إلى **«مرطبات الجسم»** (تحت «للشعر والجسم») — **لا** «عطور ← رجالية». التطبيق أخطأ لأنه يفرض تصنيف عطر على كل منتج. الإصلاح: يكشف النوع ويُسنِد التصنيف الحقيقي المقابل.

---

## 1) شجرة تصنيفات المتجر (الأسماء الرسمية للمطابقة)

**العطور**
- عطور نسائية: جديدة · جذابة · نواعم · للمناسبات
- عطور رجالية: جديدة · رسمية · فاخرة · سبورت
- عطور النيش: جديدة · رجالية · نسائية · للجنسين
- عطور الأطفال: جديدة · مميزة · مجموعات · ميني
- عطور التستر: جديدة · رجالية · نسائية · النيش
- عطور قديمة: رجالية · نسائية · عربية · فاخرة نادرة
- عطور فرمونية: جديدة · رجالية · نسائية · للجنسين
- بدائل العطور: جديدة · النيش · رجالية · نسائية

**الجمال و العناية**
- المكياج
- العناية
- العناية الكورية
- اجهزة العناية والتصفيف

**للشعر والجسم** (عطور الجسم والشعر)
- عطور الشعر
- عطور الجسم
- بودراة الجسم
- **مرطبات الجسم** ← مكان زبدة الجسم/المرطبات

**معطرات المنازل**
- معطرات هواء · معطرات مفارش · معطرات الاراضي · شموع معطرة

**العود و البخور**
- عود طبيعي · بخور فاخر · معمول · بخور ذكي

**عطور عينات ميني**
- عينات النيش · عينات رجالية · عينات نسائية · توزيعات

**إكسسوارات العطور**
- رجالية · نسائية · للمنزل · للسيارة · تغليف هدايا

**مجموعات و هدايا**
- مجموعات وأطقم هدايا · مجموعات عطور (رجالية/نسائية/جديدة/النيش)

**تصنيفات عرض/ترويج** (لا تُستخدم للإسناد التلقائي): العطور الأكثر مبيعاً · جديد مهووس · عروض مهووس.

## 2) خريطة «نوع المنتج ← التصنيف» (لإصلاح `_detect_product_type`)

| نوع المنتج المكتشَف | التصنيف الصحيح (الاسم الرسمي) |
|---|---|
| زبدة/مرطّب/لوشن جسم | **مرطبات الجسم** |
| بودرة/باودر جسم | بودراة الجسم |
| معطّر/ميست شعر | عطور الشعر |
| معطّر/ميست جسم | عطور الجسم |
| مكياج (روج، أساس، ماسكارا…) | المكياج |
| عناية بشرة (سيروم، كريم، غسول…) | العناية |
| عناية كورية | العناية الكورية |
| جهاز عناية/تصفيف | اجهزة العناية والتصفيف |
| عطر نسائي | عطور نسائية |
| عطر رجالي | عطور رجالية |
| عطر نيش | عطور النيش |
| عطر أطفال | عطور الأطفال |
| تستر | عطور التستر |
| فرموني | عطور فرمونية |
| بديل/مشابه عطر | بدائل العطور |
| عينة/ميني | عطور عينات ميني |
| معطّر منزل/جو/شمعة | معطرات المنازل |
| عود/بخور/معمول | العود و البخور |
| إكسسوار | إكسسوارات العطور |
| مجموعة/طقم هدية | مجموعات و هدايا |

> القاعدة الذهبية: **لا تفرض تصنيف عطر افتراضياً.** إن لم يُكتشف النوع بثقة ⇒ اترك التصنيف فارغاً (الفراغ أأمن من الخطأ — كما اتّفقنا في الماركة).

---

## 3) الجانب التقني (مطابقة الاسم ← المعرّف)
- التصنيف يُسنَد في سلة **بالمعرّف الرقمي** لا بالاسم. فبعد اختيار التصنيف الصحيح (أعلاه)، يجب **مطابقة اسمه ← `category_id`**.
- هذه **نفس** مشكلة الماركة: مطابقة تامّة، لا بحث ضبابي. وبما أنها تحتاج سحب تصنيفات سلة بمعرّفاتها، فالأنظف تنفيذها **في الكود مع توكن سلة** (يسحب الشجرة بمعرّفاتها، يطابق تماماً، Make يمرّر `category_id`).
- مرآة Supabase `store_categories` **فارغة** (الكاش منع تعبئتها) ⇒ تأكيد إضافي أن طريق الكود+التوكن هو الموثوق، لا Make/Supabase.

## 4) تقسيم العمل
| الطرف | المهمّة |
|---|---|
| **المبرمج (كود)** | إصلاح `_detect_product_type` ← اختيار التصنيف الصحيح من الجدول أعلاه؛ ثم مطابقة الاسم ← `category_id` بالتوكن؛ إنشاء عند الغياب |
| **المساعد (Make)** | تمرير `category_id` المُحلّ في CreateProduct (جاهز) |
