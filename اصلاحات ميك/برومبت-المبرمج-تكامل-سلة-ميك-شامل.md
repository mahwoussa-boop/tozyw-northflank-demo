# برومبت شامل للمبرمج — تكامل المشروع مع Make/سلة (إضافة المنتجات)

> الهدف: أن يُرسَل المنتج المفقود إلى Make ثم يُنشأ في سلة **جاهزاً للعرض والبيع**، بصوره المتعددة، وماركته (تُنشأ إن لم توجد)، وتصنيفه، ووصفه بقالب مهووس الذهبي، ومكوناته/مواصفاته، وكميته.

## مرجع السيناريو في Make
- الاسم: «Mahwous - إضافة منتجات جديدة لسلة (v2 مع صورة + ماركة + تصنيف)» — ID `8592565` — Webhook `3871450` — المنطقة `eu2.make.com`.
- التسلسل الحالي بعد الإصلاح: `Webhook(1) → Iterator/BasicFeeder(2) {{1.data}} → Salla Create a Product(3) → HTTP Download a file(123) → Salla Attach Image To Product(124)`.
- ‼️ حقيقة مهمة: موديول **Create a Product في سلة لا يقبل حقل صور**؛ الصور تُرفق فقط عبر موديول `Attach Image To Product` بعد الإنشاء، وهو يحتاج **ملف الصورة** (لذا تسبقه خطوة HTTP «Download a file» لتحويل الرابط إلى ملف).

## مخطط الحمولة الهدف (Webhook payload)
أرسل لكل منتج العنصر التالي داخل `{"data": [ ... ]}` (الأسماء العربية يجب أن تطابق حرفياً):

```json
{
  "NO": "1814826852",
  "product_id": "1814826852",
  "أسم المنتج": "اسم المنتج",
  "سعر المنتج": 19,
  "رمز المنتج sku": "SKU-123",
  "الوزن": 1,
  "سعر التكلفة": 0,
  "السعر المخفض": 0,
  "الوصف": "<div dir=rtl>... قالب مهووس الذهبي HTML ...</div>",
  "صورة المنتج": "https://cdn.salla.sa/.../main.jpg",
  "صور المنتج": [
    "https://cdn.salla.sa/.../main.jpg",
    "https://cdn.salla.sa/.../2.jpg",
    "https://cdn.salla.sa/.../3.jpg"
  ],
  "الماركة": "Ajmal",
  "brand_id": 0,
  "category_id": 0,
  "اسم التصنيف": "عطور",
  "الكمية": 100,
  "المكونات": "النفحات العليا: ...؛ القلب: ...؛ القاعدة: ...",
  "المواصفات": "الحجم: 100مل؛ النوع: او دو بارفيوم؛ الجنس: للجنسين",
  "جاهز_للبيع": true
}
```

ملاحظات التوافق: أبقِ `صورة المنتج` (الصورة الرئيسية) للتوافق الخلفي، وأضِف `صور المنتج` كمصفوفة. أبقِ `brand_id`/`category_id` الرقميين إن توفّرا، وأضِف دائماً `الماركة` و`اسم التصنيف` النصيين حتى يستطيع Make الإنشاء عند غيابهما.

## 1) الصور المتعددة
**الوضع الحالي:** الكاشط يلتقط الصورة الأولى فقط — `engines/async_scraper.py` (≈ سطر 1112): `images = prod.get("images", [])` ثم `images[0]`. ومخزن المنافسين `competitor_products_store.image_url` عمود واحد. والحمولة في `utils/make_helper.py` ترسل `صورة المنتج` واحدة فقط. علماً أن `engines/ai_engine.py:fetch_product_images` يُرجع حتى 4 صور.

**المطلوب في الكود (مشروع):**
1. الكاشط: خزّن **كل** روابط الصور: `image_urls = [i.get("src") for i in prod.get("images", []) if i.get("src")]`. أضف عموداً/جدولاً (مثل `image_urls` JSON) في `competitor_products_store`، أو استعمل `ai_engine.fetch_product_images` لتجميعها.
2. الحمولة (`send_missing_products`/`send_new_products` في `make_helper.py`): أضِف المفتاح `"صور المنتج": [..]` (روابط مباشرة .jpg/.png فقط، أزل المكررات، أبقِ الرئيسية أولاً).

**المطلوب في Make (سأنفّذه أنا):** بعد `Create a Product`، أضِف **Iterator** على `{{2.صور المنتج}}` ثم لكل عنصر: `HTTP Download a file` ← `Attach Image To Product` مع `default = 1` للصورة الأولى فقط و`0` لباقي الصور و`sort` تصاعدي.

## 2) الماركة (إرفاق إن وُجدت، وإنشاؤها إن لم توجد)
**الوضع الحالي:** `_resolve_brand_id` يحوّل اسم الماركة → `brand_id` من خريطة المتجر المحلية؛ وإن لم توجد يُعيد `None` فيُحذف الحقل (**لا يُنشئ الماركة**). إنشاء الماركات حالياً يدوي عبر CSV (`export_missing_brands_to_salla_csv`).

**المطلوب:** أرسل دائماً `"الماركة"` (الاسم النصي). ثم اختر أحد المسارين:
- **مسار Make (مُفضّل، سأنفّذه):** قبل ربط `brand_id` في Create a Product: `Salla > Search Brands` بالاسم → إن وُجد استخدم `id` → وإلا `Salla > Create a Brand` (الاسم [+ شعار إن توفر]) ثم استخدم `id` الناتج.
- **مسار الكود (بديل):** في `_resolve_brand_id`، عند `None` نادِ Salla API `POST /admin/v2/brands` لإنشائها ثم استخدم المعرف، وحدّث الخريطة المحلية.

## 3) تصنيف المنتج
**الوضع الحالي:** `_resolve_category_id` يحوّل اسم التصنيف → `category_id` ويُرسَل، وMake يربط `categories: [category_id]`. يعمل عند توفّر الربط.

**المطلوب:** أرسل دائماً `"اسم التصنيف"` النصي بجانب `category_id`. وللتصنيف غير الموجود طبّق نفس منطق الماركة عبر `Salla > Search Categories` / `Create a Category` في Make (سأنفّذه)، أو عبر API في الكود.

## 4) قالب مهووس الذهبي للوصف
**الوضع الحالي:** يعمل ✅ — يُولَّد عبر `engines/mahwous_core.format_mahwous_description` (أساسي) أو `utils/salla_shamel_export.generate_salla_html_description`، ويمر على `product_gate.fix_line_spacing` (RTL + line-height) ويُرسَل كـ`الوصف` (HTML). سلة تقبل HTML في الوصف.

**المطلوب:** لا تغيير جوهري. فقط تأكد أن كل منتج يجتاز `is_mahwous_description` قبل الإرسال (البوابة مفعّلة)، وأن الوصف لا يُقتطع.

## 5) المكونات والمواصفات عبر API
**الوضع الحالي:** المكونات العطرية (top/middle/base notes) تُجلب فعلاً عبر `engines/ai_engine.py` (Fragrantica + LLM) و**تُدمج داخل الوصف الذهبي** («رحلة العطر — الهرم العطري»)، لا كحقول مستقلة. لا توجد حقول مكونات/مواصفات مستقلة في موديول Create a Product بسلة.

**المطلوب (قرار تصميمي):**
- إن كان المطلوب عرضها ضمن صفحة المنتج: أبقِها في الوصف الذهبي (تعمل الآن)، وعزّزها بقسم «المواصفات» (الحجم/النوع/الجنس/الثبات) داخل نفس HTML.
- إن كان المطلوب حقولاً منظّمة: استخدم `Salla > Make an API Call` في Make لإضافة `metadata`/`product details` بعد الإنشاء، وأرسل `"المكونات"` و`"المواصفات"` نصيّاً في الحمولة. حدّد مصدر API الرسمي للمكونات (Fragrantica غير رسمي) إن أردت موثوقية أعلى.

## 6) الكمية
**الوضع الحالي:** الحمولة **لا ترسل** `الكمية`؛ وMake يضع افتراضياً 100 عبر `quantity = {{ifempty(الكمية; 100)}}`.

**المطلوب:** أضِف `"الكمية"` (رقم) إلى الحمولة في `send_missing_products`/`send_new_products`. القاعدة المقترحة: الكمية الافتراضية = 100 (موجودة كقاعدة في التصدير)، أو القيمة الفعلية إن توفّرت.

## 7) جعل المنتج جاهزاً للعرض والبيع
**الوضع الحالي:** لا يُرسَل `status`؛ قد يُنشأ المنتج بحالة افتراضية (مخفي/غير منشور) حسب إعداد المتجر.

**المطلوب في Make (سأنفّذه):** في Create a Product اضبط الحقل المتقدّم `status = sale` (القيم من RPC `GetProductStatus`، عادةً `sale` / `hidden` / `out`) ليُنشأ منشوراً قابلاً للبيع. وتأكد من `require_shipping=true` و`quantity>0`.

## 8) ربط جميع متطلبات Make بالمشروع (.env)
تأكد أن متغيّرات البيئة في `.env` تشير للويبهوك الصحيح:
```
WEBHOOK_NEW_PRODUCTS=https://hook.eu2.make.com/<توكن hook 3871450>
WEBHOOK_UPDATE_PRICES=https://hook.eu2.make.com/<توكن سيناريو تحديث الأسعار>
```
(القيم الحالية في `make_helper.py` placeholders.) ووحّد أسماء الحقول العربية بين الكود والـ Webhook interface في Make حرفياً.
