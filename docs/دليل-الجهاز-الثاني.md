# دليل تجهيز الجهاز الثاني — نسخة مستقلّة

الهدف: تشغيل **نفس التطبيق** على جهاز ثانٍ كنسخة مستقلّة. نفس الكود تماماً
(مصدر واحد على GitHub) — الفرق الوحيد هو **مكان البيانات** (يُضبط تلقائياً عبر `start.bat`).

> ⚠️ بصدق: كل جهاز يخدم التطبيق **محلياً فقط وهو مشغّل**. الجهازان لا «يتزامنان»
> تلقائياً؛ كل واحد نسخة قائمة بذاتها. للوصول الدائم المشترك استخدم نسخة Railway.

---

## الخطوات

### 1) المتطلّبات الأساسية
ثبّت على الجهاز الثاني:
- **Python 3.11** (من python.org — أثناء التثبيت فعّل خيار «Add Python to PATH»).
- **Git** (من git-scm.com).

### 2) استنساخ المستودع (مصدر الحقيقة الواحد)
افتح موجّه الأوامر واكتب:
```
git clone https://github.com/nwtsrash-lgtm/mahwous-pricing-v2.git
cd mahwous-pricing-v2
```

### 3) تثبيت المكتبات
```
pip install -r requirements.txt
```

### 4) نسخ البيانات عبر الشبكة (مرة واحدة)
من الجهاز الأول، انسخ الملفات الثلاثة من مجلد `mahwous-pricing-v2\data` إلى
**نفس المسار** `mahwous-pricing-v2\data` على الجهاز الثاني:
- `pricing_v18.db` (≈263 ميجابايت — قاعدة المنافسين)
- `missing_cache.json` (≈11 ميجابايت — كاش المفقودات)
- `pricing_cache.json` (≈14 ميجابايت — كاش التسعير، يجعل أول فتح فورياً)

> `start.bat` يضبط `DATA_DIR` تلقائياً على مجلد `data` بجانبه — لا حاجة لأي إعداد يدوي.
> ملف `competitors_list_v30.json` يأتي مع الاستنساخ (لا تحتاج نسخه).

### 5) المفاتيح (اختياري)
إن أردت ميزات الذكاء الاصطناعي: انسخ `\.streamlit\secrets.toml.example` إلى
`\.streamlit\secrets.toml` واملأ مفاتيحك. (التطبيق يعمل بدونها.)

### 6) التشغيل
انقر نقرتين على `start.bat`. سيفتح المتصفح على التطبيق.

---

## التحديثات المستقبلية للكود
عند صدور تحديث للكود على GitHub، على كل جهاز:
```
cd mahwous-pricing-v2
git pull
pip install -r requirements.txt
```
البيانات (مجلد `data`) لا تتأثّر بالتحديث (مستبعدة من git).

## الخلاصة الصادقة
- نسختان مستقلّتان من نفس الكود؛ التزامن الحقيقي عبر `git pull` للكود وعبر
  نسخ مجلد `data` يدوياً للبيانات.
- كل جهاز يعمل فقط وهو مشغّل. للوصول الدائم 24/7 من أي مكان → نسخة Railway السحابية.
